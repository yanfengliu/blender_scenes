# Repository retention

Keep reusable scene source, setup/build scripts, configuration, and useful documentation in Git.
Images, `.blend` scenes and backups, debug output, scratch work, and temporary files stay ignored wherever they are created.
Keep finished local scenes/renders and dependencies when they support future editing, reference, or rebuilding.
Remove task-owned logs, debug receipts, scratch files, and temporary artifacts once their work is complete and no active process or unresolved failure needs them.
